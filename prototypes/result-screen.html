AIに渡せる方向性

複数画像に共通して、大きなビジュアル、広い余白、セリフ体の見出し、静かな白黒・ニュートラル配色が見られます。AIには「modern editorial web gallery design」「image-led layout」「magazine-like grid」と伝えると方向性がずれにくいです。

既存の画面やビジュアルを、modern editorial web gallery design のトーンに整えてください。大きな画像を主役にし、余白を広く取り、上品なセリフ体見出しとシンプルな本文で、雑誌・ギャラリーのように見せてください。
